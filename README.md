# Edge Runner 1.3.0 (Forge 1.16.5)
- G: parkour mode on/off (or right click with the Parkour Band). H: show/hide help.
- Run (Ctrl) -> momentum. Jump at a wall -> wall run; jump again -> wall jump.
- Shift once while running -> slide (also under 1-block gaps).
- W + Space at a ledge -> vault. Jump at a ledge edge -> grab it and pull up.
- W + Space at a tall wall -> climb (A/D sideways, Shift down, S+Space push off).
- Fence / wall top: balancing walk. Katana: LMB light combo, RMB heavy dash strike.
Creative tab: Edge Runner. Font: Tektur (SIL OFL).
